## 她会做什么
**基础**
- 透明无边框小窗，默认双手交叠站着待机（呼吸、眨眼，循环无缝）。说话时换成和这句话相配的表情，没人碰她约 30 秒后自己回到待机。
- 不抢焦点：点她、她说话都不会把你正在打字的窗口切走。
- 只能开一个：已经开着时再双击，她会出来说「我已经在这儿啦～」。
- 第一次启动先打招呼，托盘弹出提示；之后每次开机按时段问候（早上、白天、晚上、深夜各有不同）。

**互动**
- 用鼠标点一下她的脑袋 = 摸头（冒小爱心）；点身体 = 戳一下；按住头不放 = 一直摸，松手她会不好意思地说一句；8 秒内连戳 3 下，会合上扇子抵着下巴、一手叉腰，小小地嘴硬一下。
- 拎起来会慌（感叹号 + 汗滴，跟着你拖的方向轻轻摆），放下说一句。
- 拖到屏幕左/右边松手：只露半个身子，鼠标靠近再探出来，离开 2.5 秒又缩回去。左右两边是分开画的，帽子、辫子、帽徽都在原来那一侧。
- 拖到屏幕上边松手：她从上面倒挂着探下来；往下拖过任务栏再松手：她从屏幕底边探出头来（只贴着任务栏上沿，不会躲到任务栏后面）。鼠标靠近探出来、离开 2.5 秒缩回去，和左右一样。那一边还接着别的屏幕时不会躲，会直接拖过去；菜单里关掉「贴边只露半身」就都不躲。
- 把文件拖给她：按扩展名说一句（.exe →「这个……我先不碰哦。」，图片、文档、表格、PPT、PDF、代码、音乐、视频、压缩包、字体、文件夹、一次拖很多个，各有台词）。

**陪伴**
- 按时段主动问候（早饭、午饭、下午茶、晚饭、23 点后劝睡、凌晨催睡），每个时段一天最多一次；23:30 后没人碰她会打瞌睡（冒 zzz），点醒她会说「嗯……还没睡呀？」。
- 节日和季节台词：元旦、春节、除夕、元宵、情人节、劳动节、儿童节、端午、七夕、教师节、中秋、国庆、1024 程序员节、万圣节、圣诞、跨年，周五晚上和周末也有。农历节日已查好 2026～2030 年的日期。
- 离开 5 分钟以上再回来，她会说「回来啦～」（离开超过半小时、隔夜回来的说法不一样）。这里只读系统的“最后一次操作时间”（Windows 的 GetLastInputInfo），不装键盘钩子。
- 每句台词都有冷却时间和权重，最近说过的尽量不重复。
- 待机小动作：隔一阵子自己笑一下、想事情、眯眼，频率可调（关 / 偶尔 / 适中 / 经常），偶尔小声嘀咕一句（只有气泡，不出声）。
- 计时器：番茄钟（专注、休息时长可调）和正计时；关掉小窗也继续计时，时间显示在她脚边。番茄结束会夸你，正计时每半小时鼓励一句，满 2 小时温柔地叫你起来动一动。
- 喝水提醒、久坐提醒：**默认关**，在菜单里打开，间隔可选。

**不打扰**
- 有全屏程序（游戏、全屏视频、F11 浏览器）在她那块屏幕上时，自动躲起来，退出全屏再回来；躲起来时动画完全停掉，开着的计时器小窗和关于页也一起藏，不出声、不弹通知；期间到点的计时提醒，退出全屏后补说一次。
- 安静一段时间：不主动说话、不出声，点她还会回应。时长可以选 15 分钟、30 分钟、1 小时，也可以自己填分钟数（1 分钟到 24 小时）。
- 你离开电脑时，动画降到每秒 4 帧省电。

## 托盘和右键菜单（两处一样）
单击托盘图标：显示 / 藏起来。右键托盘图标或右键她：
- 显示她 / 先藏起来、总在最前
- 安静一段时间（在第一屏靠前）：15 分钟、30 分钟、1 小时，或「自定义…」填分钟数（1–1440）。安静中最上面这一项是「结束安静（还剩 N 分钟）」，点一下提前结束；再选一个时长会按新的时长重新算
- 飘着 / 长脚：两项互斥切换，默认飘着。长脚默认 75%，两种模式分别记住大小；切换时保持脚底位置，必要时拉回屏幕内。v0.3.8 起长脚模式 8 段动作（待机、笑、得意、思考、两个保持动作、挥手、合扇叉腰）都是统一画风的整身重画，全部有腿。计时牌在上半身底部，上方探头继续关闭。
- 大小：滑块 20%～150%，另有 50/75/100/125/150% 快捷档；调完停手约 1 秒，她会问一句「这个大小可以吗？」（安静模式、藏起来、全屏时不问，20 秒内不重复；开机恢复大小不问）
- 声音：能看到装没装语音包；静音、音量四档（默认 35%）
- 提醒和小动作：离开回来打招呼（默认开）、按时段问候（默认开）、喝水 / 久坐提醒（默认关）和间隔、待机小动作频率、全屏时躲起来、贴边只露半身
- 计时器（番茄钟 / 正计时）…
- 找回她（回到主屏幕中间，跑丢了就点这个）
- 开机自动启动（只有 Windows；只在你勾选时写入「当前用户」的启动项 `HKCU\Software\Microsoft\Windows\CurrentVersion\Run\ZhangguiPet`，取消勾选就删掉。旧版留下的自启项不会被悄悄删掉：菜单里会提示，等你点这一项时才一并清掉）

- 关于…（署名与授权）
- 退出

## 设置存在哪
- Windows：`%APPDATA%\ZhangguiPet\`；Linux/macOS：`~/.config/ZhangguiPet/`。
- 从旧版（v0.3.3 及以前）升级：第一次启动时，如果新文件夹里还没有设置，会从旧版的设置文件夹把 `settings.json` 读过来一次（旧文件夹原样保留，不删不改）。
- 如果那里写不进去（比如安全软件拦了陌生程序写 AppData），她会依次改用：`%LOCALAPPDATA%\ZhangguiPet\` → 程序旁边的 `data\`（便携模式）→ 临时文件夹 `%TEMP%\ZhangguiPet\` → 实在都不行就只记在内存里（关掉就忘）。每个位置都会先真的写一个小文件试试；换了地方会温柔地提一句（只提一次，不显示路径）。把 ZhangguiPet.exe 加进安全软件的信任后，下次就会回到 `%APPDATA%`（之前存在别处的设置不会自动搬过去）。
- 启动时出错不会再弹 Python 原始报错框：会在上面那些目录之一留下 `ZhangguiPet-crash-时间.log`，并弹一个中文提示框。运行中某个小功能出错只记录，不打扰。
- 单实例（只开一个）在 Windows 上用系统命名互斥量 + 事件，不依赖任何文件。
- `settings.json` 存设置和位置。位置按“哪块屏幕 + 在这块屏幕上的相对位置”保存，换分辨率、拔掉副屏后启动会检查，不在屏幕里就挪回来。文件坏了会自动改名成 `.broken`，换回默认设置。
- `zhanggui-pet.log` 是事件日志（最多 256KB，自动轮换）。
- 完全卸载：删掉程序文件夹，再删掉上面这个配置文件夹；开过“开机自动启动”的话先在菜单里取消。

## 语音（可选离线语音包）
主程序压缩包**不含**全量语音，运行也不要 API key。没有语音文件时，她照旧只冒文字气泡，不报错、不联网。

- 文件名和台词 id 对齐：`assets/voice/<台词id>.wav`（优先）或 `.ogg`，id 见 `voice_plan_pet.json`。有这个文件就放，没有就只显示气泡。
- 菜单「声音」里能看出状态：没装是「还没装语音包，现在只有文字气泡」；装了是「语音包：已装 N 句」。还可以静音、调音量（默认 35%）。
- 播放不依赖 QtMultimedia，主路径也不调用在线 TTS：Windows 用系统自带的 winsound（wav），macOS 探测系统 `afplay`，Linux 用 paplay、aplay 或 ffplay。macOS 上 `.ogg` 交给 `afplay`；Windows 的 winsound 只播 wav。
- **另下语音包（可选）**：主 zip / app **不要**把 128 句打进去。语音包发布后，把 `<台词id>.wav`（或 `.ogg`）放进程序里已经有的 `assets/voice/`（和精灵图同一层，里面有一份说明）。源码或源码包就是仓库里的 `assets/voice/`。Windows 安装包在 `ZhangguiPet.exe` 旁边的 `_internal\assets\voice\`。macOS 安装包在 `ZhangguiPet.app/Contents/Frameworks/assets/voice/`（`Contents/Resources/assets/voice/` 是同一目录）。放好后重新打开菜单就能看到句数。详见 `assets/voice/README.md`。
- 自己准备音频（仍然不在主程序里联网）：`voice_plan_pet.json` 是配音计划（128 句，约 1545 字，带情绪标签）。在你自己的电脑上合成后，执行 `python tools/import_voice.py <合成结果文件夹>`，会转成 24kHz 单声道 wav，裁掉首尾静音，统一响度，放进 `assets/voice/`。改了台词就重新跑 `python tools/export_voice_plan.py`。这些 wav 留在本机，不必提交进主仓库。

## 给 v0.4 留的接口（可选联网聊天 / TTS，默认关）
本体只通过 `pet_brain.py` 要台词：`brain.line(类别)` 必须同步返回、不能卡界面；`brain.chat(文字, 上下文, 回调)` 在 v0.3 里固定返回 False。
v0.4 计划新建 `pet_online.py`，只有在设置里填了 key 并打开开关时才加载：
- `OnlineBrain` 继承 `LocalBrain`：在后台线程请求用户自己填的聊天 API，15 秒超时，让模型返回 `{"text", "expr"}` 来配表情；出错或超时就退回离线台词。
- TTS 也一样：有预录语音先放预录，新台词才调用用户自己的 TTS，音频缓存在配置目录。
- key 用 Windows 自带的 DPAPI 加密，存在 `%APPDATA%\ZhangguiPet\secrets.bin`，不写进 settings.json、日志和诊断文件；只发给用户自己填的服务商，不经过我们任何服务器；代码开源可查。

## 性能（测试机实测，Linux + Xvfb 虚拟屏，盒子同时在跑别的任务，负载约 9/8 核）
| 情况 | CPU（单核占比） | 内存（进程私有） | 内存（含共享的 Qt 库和字体） |
|---|---|---|---|
| 100%，有人在用（12 帧/秒） | 0.7～1.2% | 约 82MB | 约 133MB |
| 100%，人离开（4 帧/秒） | 0.4～0.8% | 约 82MB | 约 133MB |
| 150% | 约 1.2% | 约 117MB | 约 169MB |
| 50% | 约 1.0% | 约 47MB | 约 100MB |
| 动画停掉（躲起来时） | 约 0.05～0.1% | — | — |
换算到 8 线程 CPU 的任务管理器，大约是 0.1～0.15%。做法：每个大小的帧只缩放一次并缓存，待机帧常驻，其他表情用到才解码，回到待机 60 秒后释放；每段动画只设一次窗口遮罩；平时只重画她身体那块。

## 在 Windows 上运行（开发模式）
需要 Python 3.10 及以上（推荐 3.12），Win10 / Win11（PySide6 不支持 Win7）：
```powershell
py -3.12 -m venv .venv
.venv\Scripts\pip install PySide6-Essentials
.venv\Scripts\pythonw zhanggui_pet.py
```

## 打包（推荐 onedir + zip，单个 exe 更容易被杀毒误报）
```powershell
.venv\Scripts\pip install pyinstaller
.venv\Scripts\python -m PyInstaller --noconfirm --clean packaging\zhanggui_pet.spec
```
spec 里已经写好排除的 Qt 模块、图标和 exe 版本信息（产品名「掌柜台桌宠」，公司名留空）。
打包后把 `README.md`、`LICENSE.txt`、`THIRD_PARTY_NOTICES.txt` 和 `licenses\` 复制进 `dist\ZhangguiPet\`，再把整个文件夹打成 `ZhangguiPet-v<版本>-win-x64.zip`。不要用 UPX 压缩。附上 SHA256，可以的话再附一个 VirusTotal 链接。没签名的程序第一次运行时，SmartScreen 可能提示，点「更多信息 → 仍要运行」。

## 还没在真 Windows 上验证的（需要你实机测一下）
全屏检测（Win32 前台窗口 = 整块屏幕；普通最大化窗口不算）、GetLastInputInfo、开机自启写注册表、winsound 放声音、托盘里的滑块、多屏 / 混合缩放（100% + 150%）、分层窗口的点击穿透（不行就设环境变量 `ZHANGGUI_PET_NOMASK=1`）、SmartScreen。

## 调试用环境变量（平时用不到）
`ZHANGGUI_PET_DEBUG=1` 打印日志；`ZHANGGUI_PET_HOLD=秒` 表情停留时间；`ZHANGGUI_PET_AWAY_SECS=秒` 多久算离开；`ZHANGGUI_PET_ORDER=台词id,…` 固定台词顺序（录视频用）；`ZHANGGUI_PET_AUTOQUIT=秒`；`ZHANGGUI_PET_CONFIG_DIR=路径`；`ZHANGGUI_PET_NOMASK=1`；测试用的 `ZHANGGUI_PET_SIM_FULLSCREEN_FILE`、`ZHANGGUI_PET_SIM_IDLE_FILE`、`ZHANGGUI_PET_CMD_FILE`、`ZHANGGUI_PET_NO_AUDIO`、`ZHANGGUI_PET_NO_OPEN`，只有设置了才生效。`ZHANGGUI_PET_CMD_FILE` 只在源码运行时有效（打包后的 exe 完全不读），而且只认白名单动作（`pat`、`poke`、`scale 0.8`、`line <台词id>`、`timer_remaining 3` 等，见 `zhanggui_pet.py` 的 `DEV_ACTIONS`），不执行任何代码。

## v0.3.5 更新（按代码审阅修的一轮，详见 `CHANGELOG.md`）

- 录屏用的命令开关不再执行任意代码，只认白名单动作；打包后的 exe 完全不读命令文件。
- 全屏检测：Windows 接口声明写全，出错会记进日志（只记错误类型，一分钟最多一条）；`Windows.UI.Core.CoreWindow` 只在属于开始菜单/搜索这类系统进程时才忽略。
- 藏起来、鼠标松开的消息丢了时，会清掉“正在摸/正在拖”的状态；「先藏起来」后马上点「找回她」，不会再被藏掉。
- 全屏躲起来时，计时器小窗、关于页一起藏，不出声；期间到点的计时提醒，退出全屏后补说一次。
- 严格冷却真的严格了：冷却中的台词不会再被选中。
- 同一秒有好几件事想说时只说最重要的一句（计时结束 > 回来啦 > 久坐 > 喝水 > 时段问候）；没说出口的问候不算已问候。
- 她靠近屏幕顶时，气泡不会再跑出屏幕。
- 诊断日志只导出固定字段，屏幕名换成编号，不认识的文件扩展名记成 other。
- 拖文件给她：只接受“本地文件 + 允许复制”的拖放。

## v0.3.2 更新

- **躲屏幕边换成新立绘（B 方案）**：拖到屏幕左/右边松手，她会贴着墙害羞地露出来；鼠标靠近时换成歪头探出来的样子（0.15 秒淡入淡出，位置和大小都不跳）。左边用的是镜像图，所以帽子和辫子会换到另一侧（以后可以单独画左边的）。
- **托盘图标出不来时不会再“藏丢”**：启动时会记录托盘是否可用、是否真的加上；托盘不在时，「先藏起来」会变成「躲到屏幕边上」。藏之前她会说「我在右下角等你哦～」，托盘也会弹提示。再双击一次 exe 永远能把她叫出来。“藏起来”不会记到下次启动。
- **托盘为什么会出不来**：如果 exe 放在被系统标成“低完整性”的文件夹里（有些工具/沙盒会这样标），Windows 会让她以“低权限”运行：既写不了 AppData，也加不了托盘图标。把整个 ZhangguiPet 文件夹挪到普通位置（比如某个盘根目录下的普通文件夹）就好。她检测到这种情况会提醒一句。
- 测试用环境变量：`ZHANGGUI_PET_SIM_NO_TRAY=1`（假装没托盘）、`ZHANGGUI_PET_SIM_LOW_IL=1`（假装低权限）。
